# Лендинг LDNIO WL02

Готовый одностраничный прототип: `index.html` + адаптивный CSS, блоки преимуществ/характеристик/FAQ и форма заказа.

## Запуск локально

Для просмотра дизайна можно открыть `index.html`. Форма отправки будет работать после деплоя на Vercel (или другом хостинге, поддерживающем serverless functions).

## Подключение Telegram

**Важно:** токен бота нельзя размещать в `script.js`, HTML или публичном GitHub-репозитории.

1. В @BotFather немедленно отзовите ранее опубликованный токен командой `/revoke` и получите новый: старый токен уже виден в истории чата и считается скомпрометированным.
2. Напишите созданному боту `/start`.
3. Разверните репозиторий на https://vercel.com/.
4. В Vercel откройте Project → Settings → Environment Variables и добавьте:
   - `TELEGRAM_BOT_TOKEN` — новый токен от BotFather;
   - `TELEGRAM_CHAT_ID` — `127138256`.
5. Сделайте Redeploy.

После этого заявка из формы отправляется папе в Telegram через `/api/order`. Номер телефона сам по себе не является Telegram Chat ID.

## Настройка

Цена сейчас указана как 3 000 ₴ в `index.html`, `script.js` и `api/order.js`. Перед публикацией замените демонстрационные тексты/иллюстрацию на собственные фотографии товара и добавьте реквизиты продавца, условия возврата и доставки.
